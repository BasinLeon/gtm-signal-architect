### Key Design Decisions

1. **TailwindCSS via CDN**: Rapid prototyping without build step
2. **Monospace Font**: Terminal aesthetic throughout new sections
3. **Dark Theme**: `bg-[#0a0a0a]` matches developer tools
4. **Glowing Effects**: `shadow-[0_0_10px_rgba(...)]` for status dots
5. **Responsive**: `md:` breakpoints for mobile support
6. **Color Coding**: Blue (past), Green (current), Gray (legacy)

### Browser Compatibility

- **Modern Browsers**: Full support (Chrome, Firefox, Safari, Edge)
- **Mobile**: Responsive with `flex-col` → `md:flex-row`
- **Accessibility**: High contrast terminal colors (green on black)
- **Performance**: Static HTML, no JavaScript dependencies
